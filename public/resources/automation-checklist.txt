Start with a repeated task you understand. For example, you could track quotation requests from WhatsApp, assign each one to a team member and set a follow-up reminder. Test the steps manually before paying for automation tools.

2. CHECK WHETHER IT IS A GOOD FIT
[ ] The task repeats regularly.
[ ] Its inputs and expected output are clear.
[ ] The current steps can be written down.
[ ] You can spot and correct errors.
[ ] Someone will own the process after it is automated.
[ ] The people and tools involved only receive the customer details they need.

3. MAP THE STEPS
Trigger -> input -> action -> review -> next step

Example to adapt, not a system already connected to your business:
New quotation request -> record the request -> assign a person -> check the details -> send an approved reply and set a follow-up date.

Use your existing spreadsheet or business system to test a few enquiries first. You may only need a reminder or a clearer process. AI can help draft a message; a person should check its details before sending it.

4. PLAN FOR PROBLEMS
What should happen if information is missing?
Who is notified if a step fails?
How can someone pause the process?
Where will records be stored, and who can access them?

What happens if an internet or tool outage interrupts the task?
Which steps can we still do manually?

5. CHECK THE COST AND RESULT
Time spent per task before the trial: ____________________
Time spent per task during the trial, including checking: ____________________
Errors or missed follow-ups before and during the trial: ____________________
Setup, subscription and messaging costs in KES: ____________________
Person responsible for reviewing the process: ____________________
Review date: ____________________

Compare the results before expanding the setup. Include time spent fixing errors as well as the tool costs. Do not assume it saves time or money until you have measured it.
